feat: 从零重做 —— 大肥鱼·海景小屋

全新项目，替换旧的 3D 桌面方案。

- 场景：海景小屋（落地窗、海面 shader、沙滩、沙发、床、小桌、懒人窝、台灯）
- 角色：程序化圆滚滚蓝灰小鲸鱼（短鳍、大尾巴、肉脸、浅蓝居家服）
- 状态机：心情/饱腹/精力三条数值 + 加权行为决策 + 夜间休眠 + 饥饿降级
- 行为：睡觉/发呆/看海/刷视频/写日记/干饭/找你聊天/整理小屋
- 日记：情绪波动或长独处触发，每天最多 3 次
- 状态桥 server/bridge.mjs：托管前端 + WS 推送 + state/ 持久化 + POST /state 写入
- 前端可被外部 Agent 接管，断开后自动回落本地自主循环
- README 记录清单中各 GitHub 地址的核实结果（7 个无效）
